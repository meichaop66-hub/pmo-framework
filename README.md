# 规则骨架（F层）方法论

> 一套可复用的"让 AI 干活"的行为规则体系——从 PMO 骨架迭代而来，面向智能助手协作场景的通用规则框架。

## 📖 项目简介

本仓库是**规则骨架（F 层）**的唯一真源，包含核心规则篇（给人看）与执行细节篇（给 AI 看）。规则骨架定义了一套让智能助手在协作中守边界、高质量交付的行为规则，适用于从轻量任务到完整项目管理的各类协作。

**唯一真源**：本仓库（Gitee）——所有版本迭代、接棒恢复均以此为准。
**展示镜像**：飞书（骨架PMO展示区）——owner 阅读查看用，单向同步，不反向改。
